# WeatherAI Dashboard

A React application integrating WeatherAI's API for real-time weather data and 5-day forecasts.

## Live Demo

[https://weather-ai-dashboard.netlify.app](https://weather-ai-dashboard.netlify.app)

## Setup Instructions

### Prerequisites

- Node.js (v16 or higher)
- npm or yarn
- WeatherAI API key (starts with `wai_`)

### Installation

```bash
# Clone the repository
git clone https://github.com/YOUR_USERNAME/weather-ai-dashboard.git
cd weather-ai-dashboard

# Install dependencies
npm install

# Start the app
npm start
